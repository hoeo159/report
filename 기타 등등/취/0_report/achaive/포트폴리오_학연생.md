# Main Projects

### 컴퓨터그래픽스 연구실 학부연구생 (2024.08 ~ 2025.07)

#### 프로젝트 개요

&ensp;성균관대학교 컴퓨터그래픽스 연구실에서 학부연구생으로 활동하며 두 가지 프로젝트를 담당했습니다. 첫째는 Glare Rendering을 Fourier Series 기반 모델로 개선하는 그래픽스 연구이며, 둘째는 IITP 과제로 진행한 CUDA 기반 Vector DB 인덱스 빌드 가속 연구입니다.

#### 주요 역할

##### 1. Fourier Series 기반 Real-time Glare Rendering

- 수십~수천 개의 ghost가 누적되어 형성되는 veiling glare에 대해, glare 개수 K에 선형 이상으로 비례하던 기존 방식의 한계를 극복하는 parametric 표현 연구([보고서 활동](https://github.com/hoeo159/report/tree/main/cg/vglare))
- 적분 형태의 후보 함수(다항식, 삼각함수, Fourier-Bessel, 2D Gaussian)를 비교, 1D series 곱으로 분해되는 2D Gaussian 채택
- **Precompute** : 삼각함수 덧셈정리로 ghost 좌표 ($x_k$, $y_k$)와 픽셀 ($x$, $y$)를 분리, K개 glare의 공통항 4종 coefficient를 `initial_update()`에서 누적해 SSBO에 적재
- **Render** : fragment shader는 N×M basis 가중합만 평가, mipmap min/max를 UBO로 셰이더에 전달해 동적 정규화로 saturation 해소
- 결과: 복잡도 O(K) → O(N²), K=1000 기준 0.311ms → 0.082ms, ghost 수와 무관하게 평균 4000–5000 FPS 유지(K : glare 개수, N : 푸리에 차수)

##### 2. CUDA 기반 Vector DB 인덱스 빌드 가속

- 1536차원의 고차원 대용량 데이터에 대한 GPU 파티셔닝 가속 담당, K-means kernel과 대용량 데이터 로딩 경로를 양 갈래로 최적화 ([링크](https://cgskku.github.io/vdb/vdb/web/kmeans/))
- **K-means kernel (shared memory)** : centroid를 chunk 단위로 shared memory에 적재하고, 1 thread block ↔ 1 data point로 매핑해 각 thread가 sequential dimension을 처리하도록 재설계.
- **대용량 데이터 로딩 (pinned + async)** : GPU 메모리 한도를 초과하는 데이터셋을 위해 K-means 알고리즘과 분리된 데이터 전송 경로를 설계. host pinned memory와 GPU 메모리를 각각 두 영역으로 나눠 한쪽은 kernel 실행 ↔ 다른 쪽은 다음 batch 업로드를 병행하는 2-way async stream 파이프라인을 구성.
- 결과 : 1M × 1536, K=25, iter=10 기준 3.256s → 1.626s (NVIDIA 4090)

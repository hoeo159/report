# Experience

### Vueron Technology, Perception Engineer Intern (2023.04 ~ 2023.12)

#### 프로젝트 개요
&ensp;자율주행 객체 인지 모델의 성능을 분석하기 위해 모델 예측 결과를 시각적으로 확인하고 정량적으로 평가할 수 있는 도구를 개발했습니다. 또한 LiDAR 데이터 처리 과정의 병렬화를 통해 데이터 전처리 성능을 개선했습니다.
#### 주요 역할
##### 1. 딥러닝 모델 평가 툴 개발
- 객체 인지 모델의 prediction과 ground truth를 비교하여 IoU 기반 성능 평가 시스템 구현
- 매 프레임마다 검출 결과를 분석하여 정확도 및 이상치(outlier) 탐지 기능 구현
- OpenGL 기반 시각화 도구 개발을 통해 객체 인지 결과를 직관적으로 확인할 수 있는 환경 구축
##### 2. 데이터 전처리 병렬화
- 기존 serial 방식의 LiDAR data parsing pipeline을 병렬 처리 구조로 개선
- 타겟 보드 환경에 맞게 CUDA, OpenMP, OpenCL 기반 병렬 코드 구현
- Unit Test 및 Performance Test를 통해 GPU 메모리 사용량과 처리 성능 분석

#### 결과
- 40,000 ~ 80,000개의 LiDAR point 데이터를 병렬적으로 처리
- 데이터 전처리 단계에서 평균 1.2배 ~ 최대 2배 성능 향상(평균 22ms > 최대 10ms)
- 자율주행 perception 모델 성능을 정량적으로 분석할 수 있는 평가 지표 제공

1. 현대로템에 지원한 이유와 입사 후 본인이 보유한 경험을 어떻게 활용할 계획인지 작성해주세요. 

저는 사람과 직접 맞닿아 있는 소프트웨어를 개발하고 싶다는 목표를 가지고 있습니다. 특히 뷰런 테크놀로지 산학 프로젝트에서 자율 주행 객체 인지 파이프라인을 다루며, 처리 지연 하나 하나에 대한 최적화가 시스템 전체의 안정성에 직결된다는 것을 실감했습니다. 그 경험이 계기가 되어 더 많은 사람의 안전과 직결되는 실시간 시스템을 만드는 일에 관심을 갖게 되었고, 제어, TCMS, 통신 시스템을 개발하는 신호통신 직무에서 제가 쌓아온 역량을 가장 의미있게 발휘할 수 있는 곳이라고 판단했습니다.

산학 프로젝트에서는 40000~80000개의 LiDAR 데이터 포인트 데이터를 실시간으로 처리하는 파이프라인을 C/C++로 설계하고, CUDA, OpenCL을 타겟 보드 환경에 맞춰 적용했습니다. 그 결과 데이터 파싱 시간이 기존 22ms 정도에서 최대 10ms까지 단축했습니다. 이 과정에서 단순히 동작하는 코드가 아니라, 하드웨어 제약과 실시간 요구사항을 동시에 만족하는 구조를 설계하는 것이 핵심임을 배웠습니다. 또한 Unit Test와 Performance Test를 직접 설계하여 각 처리 단계의 지연 시간과 GPU 메모리 사용량을 측정하고, 병목 구간을 데이터 기반으로 특정하는 방식을 익혔습니다.

입사 후에는 이 경험을 두 방향으로 직무에 연결하고 싶습니다. 첫째, 실시간 데이터 처리와 C/C++ 시스템 설계 역량을 열차제어, TCMS 소프트웨어 개발에 적용하겠습니다. 둘째, 측정 기반의 검증 경험을 단위 및 통합 검증 시험 업무에 활용하여 시스템 신뢰성 확보에 기여하겠습니다. 선임 연구원 분들과 적극적으로 상호작용하여 도메인 지식을 빠르게 익히고, 새로운 기술과 환경에 스스로 뛰어들어, 현대로템의 기술 신뢰성을 함께 높여나가는 개발자가 되겠습니다.

2. 지원 직무를 수행하기 위해 필요한 핵심 역량은 무엇이며, 본인이 해당 역량을 갖추고 있는지 경험과 성과를 중심으로 작성해주세요.

신호 통신 직무의 핵심 역량은 기업의 요구 사항을 정확히 분석하고, 이를 수학적 구조적으로 풀어 구현과 검증까지 진행하는 소프트웨어 설계 역량이라고 생각합니다. 저는 이러한 문제 해결 과정을 컴퓨터 그래픽스 학부 연구생으로 활동하면서 경험했습니다.

당시 맡은 과제는 이전 사수들이 수학적 모델링의 어려움으로 방치해두었던 Glare Rendering 최적화였습니다. 기존 방식은 광원 개수에 비례해 연산량이 증가하는 O(K) 구조로, 광원이 많아질수록 실시간 렌더링 성능이 급격히 저하되는 것이 핵심 문제였습니다. 아무도 해결하지 못한 과제였지만, 직접 자원하여 맡았습니다.

원형 함수를 재현하기 위해 베셀 함수로 접근했지만 극좌표계 기반이라 사각형 디스플레이 환경에 맞지 않았고 재현율도 떨어졌습니다. 다른 함수들은 불연속 지점으로 인해 퀄리티가 떨어지거나 analytic한 적분이 불가능했습니다. 수학 서적을 찾아보고 타 학과 친구들에게 조언을 구하며 접근 방법을 계속 바꿔나갔습니다. 그러다 Gaussian Splatting 논문을 읽다가 영감을 얻어, Glare의 종 모양 특성을 2D Gaussian으로 근사하면 closed-form 적분이 가능하다는 것을 발견했고, 푸리에 급수의 기저가 x, y축으로 독립적이라는 점을 활용해 계수를 사전 계산하는 알고리즘을 설계했습니다. 이를 GLSL로 구현하고 UBO, mipmap을 활용해 OpenGL에 적용한 결과, 렌더링 복잡도를 O(K)에서 푸리에 차수 기반으로 전환하여 광원 수에 독립적인 성능을 확보했습니다.

이 경험은 문제를 정의하고, 다양한 접근을 시도하고, 수학적 모델을 코드로 구현하여 성능으로 검증하는 전 과정을 직접 설계하고 수행한 것이었습니다. 이러한 경험을 바탕으로 고객과 기술 요구사항을 분석해 문제를 해결하고, 기능 및 성능 검증 시험을 수행하는 신호통신 직무에서 이 역량을 발휘하겠습니다.

3. 현대로템의 인재상과 본인이 얼마나 부합하는지 구체적인 사례를 바탕으로 작성해주세요. 

저는 현대로템의 인재상이 동료와 조직에 대한 신뢰를 바탕으로, 도전을 두려워하지 않고 스스로 성장하는 사람이라고 생각합니다.

대학교 3학년 때 6인 팀으로 Vector Database와 LLM을 결합한 교내 공지사항 검색 서비스를 개발했습니다. 시작 직후 팀 리더가 휴학으로 이탈하며 연락이 두절되는 상황이 발생했습니다. 역할과 목표가 흐트러지면 팀이 쉽게 흩어진다고 판단해 제가 직접 리더를 자원했습니다. 팀원들은 전공과 개발 속도가 모두 달랐기 때문에, 각자의 기술 구현 역할을 정하는 것보다 소통 구조를 먼저 설계하는 것이 갈등을 사전에 방지하는 데 더 중요하다고 생각했습니다. When2Meet으로 공통 시간을 확보해 정기 온라인 회의를 진행하고, Notion에 일정과 이슈를 부담 없이 기록해 누구든 프로젝트 흐름을 따라올 수 있게 했습니다. 프론트와 백엔드 간 JSON 형식과 로딩 정책을 사전에 합의하여 병렬 개발 시 충돌을 최소화하는 구조를 잡았고, 개발에 어려움을 겪는 팀원이 있을 때는 스터디룸을 빌려 함께 속도를 맞추는 방식을 택했습니다. 저는 팀 리더 역할과 함께 AI 파트를 담당하여 교내 공지사항 자동 크롤러를 구현하고, Pinecone 기반 벡터 인덱스를 구축했으며, 한국어 SBERT를 교내 공지 도메인에 맞게 파인튜닝해 검색 품질을 높였습니다. 그 결과 이탈자 없이 프론트-서버-Vector DB가 연동된 프로토타입을 완성했습니다.

이 경험을 통해 팀을 이끄는 것은 기술력보다 방향을 잡고 소통을 설계하는 일이라는 것을 배웠습니다. 위기 속에서도 조직을 신뢰하고 담대하게 행동하며, 팀의 다양성을 존중하고 수용하면서, 새로운 역할에 스스로 뛰어들어 성장해온 저는 현대로템이 추구하는 인재상과 맞닿아 있다고 생각합니다. 신호통신 직무에서도 다양한 전문가들과 협업하며 팀 전체가 같은 방향으로 나아갈 수 있도록 기여하겠습니다.
